# UH Maui College - Course Catalog (Week 8a)

## Overview
This project is a simple web-based course catalog using JSON data. It displays courses, instructors, schedules, and topics in a responsive card layout. Users can search and filter courses by department, credits, or keywords.

## Features
- Load course data from `sample-data.json` with error handling
- Display all courses in responsive cards
- Search courses by course code, title, instructor, or topics
- Filter courses by department and credit hours
- Color-coded enrollment indicators (Open / Filling / Full)
- Mobile-friendly and accessible design
- Easy to add or export courses using JSON
