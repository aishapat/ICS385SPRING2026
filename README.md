#week8a:University Catalog System
is a simple web application that displays a university course catalog using JSON data file. Users 
can search, filter, and view courses by department, credits, and other criteria.
-JSON file: 'basic-json.json'
-Open the URL in a browser no installation needed
-Code comments explains the key functions in index.js

#week8b:Integrated Campus Design
This is a web based dasboard that displays campus related information including course, weather, and jokes. The 
dashboard loads course data from a local JSON file and integrates external APIs to display weather and jokes.
